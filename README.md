# 🏦 마마트레이딩 (MAMA TRADING) 맞춤 대출 서비스

> **신용 영향 없는 1분 안심 가심사 · 15분 당일 입금 맞춤 대출 랜딩플랫폼 & 데이터베이스 연동 시스템**

---

## 🌟 프로젝트 개요

**마마트레이딩(MAMA TRADING)** 맞춤 대출 플랫폼은 복잡한 서류 제출과 지점 방문 없이, 모바일 및 웹 환경에서 3분 만에 신용점수 하락 없는 안심 가심사 한도조회와 15분 내 당일 입금을 지원하는 프리미엄 대출 서비스 랜딩플랫폼입니다.

---

## ✨ 핵심 기능

1. **🎬 시네마틱 스티키 패러랙스 메인 히어로**:
   - 스크롤 이동에 따라 좌측 `SPEED LOAN`과 우측 `LOW RATE` 빅 타이틀이 중앙으로 모이고 화면이 고정되는 스크롤 반응형 인터랙션
2. **📱 모바일 최적화 콤팩트 신청 바**:
   - 상단 1라인(`성함` / `연락처` / `약관 동의`)과 하단 2라인(`희망금액` 드롭다운 통배치)으로 텍스트 짤림을 원천 방지한 모바일 전용 폼
3. **💬 모바일 3.5초 Auto-Play 실시간 이용후기 슬라이더**:
   - 8가지 대출 상황별 실제 고객 후기 카드가 모바일 환경에서 3.5초마다 부드럽게 자동 넘어가며, 터치 시 일시 정지 기능 제공
4. **🖼️ 4단계 스피드 대출 절차 브랜딩 카드**:
   - `pr_1` ~ `pr_4` 고화질 브랜드 이미지 배경과 세련된 다크 오버레이를 조합한 입체적 절차 안내
5. **💳 5대 맞춤형 대출 상품 라인업**:
   - 직장인, 무직자/취준생 비상금, 사업자 운전자금, 여성/주부 우대, 고금리 대환 대출 상품별 정보 제공
6. **🗄️ 백엔드 데이터베이스 비동기 접수 시스템**:
   - 신청 폼 제출 시 비동기(AJAX) 전송을 통해 데이터베이스에 대출 신청건 및 퍼스널 이력 로그 자동 수집

---

## 🛠️ 기술 스택 (Tech Stack)

* **Backend**: Node.js, Express.js
* **Frontend**: HTML5, Vanilla CSS3 (CSS Variables & Flexbox/Grid), Vanilla JavaScript (ES6+), EJS View Engine
* **Database**: MySQL / MariaDB
